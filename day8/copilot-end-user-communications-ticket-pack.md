# Copilot Support Updates - End-User Communication Pack

## Purpose
This document provides plain-English responses you can send to users for the current set of Copilot support tickets.

---

## Ticket 1 - Finance lead cannot summarize Q3 board pack in SharePoint
Subject: Update on your Copilot board pack request

Thanks for reporting this. The most likely reason is that the board pack has higher security protection (or special access rules), so Copilot cannot use it even though you can open it directly.

What you can do now:
1. Open the board pack and confirm the file is accessible with your work account (which you already have).
2. Share the exact file link with IT so we can check the file label/access settings.
3. If needed, we will work with the data owner to confirm whether Copilot use is allowed for that content class.

What to expect:
- If this is a protection policy issue, we will confirm the policy behavior and provide an approved workaround where possible.

## Ticket 2 - New hire cannot get Copilot in Outlook to use recent emails
Subject: Update on Copilot not finding your recent emails

Thanks for raising this. Because your account is very new, Copilot may need more time to catch up with mailbox indexing before it can use your recent content well.

What you can do now:
1. Keep using Outlook as normal for the next business day.
2. Sign out/in once in Outlook and confirm you are using your company work account.
3. Retry Copilot after a short wait period.

What to expect:
- This usually improves automatically after indexing catches up.
- If it does not improve, IT will check license and client readiness next.

## Ticket 4 - Sales rep cannot find externally shared contract in Teams
Subject: Update on Copilot and externally shared contract

Thanks for flagging this. The file appears to be shared from another organization via guest/external link, which often limits what Copilot can retrieve.

What you can do now:
1. Open the contract directly from the shared link to confirm manual access.
2. Ask the file owner to place a copy in an approved internal location if Copilot support is needed.
3. Share the link with IT if access still fails so we can validate sharing scope.

What to expect:
- Copilot works best with content stored and permissioned inside your own tenant.
